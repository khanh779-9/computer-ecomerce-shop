# Minh Tuấn Computer Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Refactor the supplied single-file React/Tailwind storefront into a maintainable React/pnpm frontend, Java 17 Spring Boot backend, PostgreSQL database scripts, and optional Redis/MinIO infrastructure while preserving the source UI and flows.

**Architecture:** Modular monolith backend with `config`, `common`, and feature-oriented `modules`. Frontend uses separate external/customer and internal/staff route trees with independent layouts. PostgreSQL is the source of truth; Redis and MinIO are integration points, not requirements for running the Java app itself.

**Tech Stack:** React + TypeScript + Vite + pnpm + Tailwind CSS + shadcn/ui conventions; Java 17 + Spring Boot + JPA + Flyway; PostgreSQL; Redis; MinIO.

**Spec:** Derived from the supplied `Văn bản đã dán (1).txt` and the user's requested target structure.

## Global Constraints

- Preserve the supplied Minh Tuấn Computer storefront concept, Vietnamese copy, product mock data, SVG product artwork, search/filter/sort, product detail, cart drawer, checkout, countdown, and success modal.
- Frontend package management uses pnpm; include `pnpm-lock.yaml` placeholder-free only when generated by pnpm.
- Backend targets Java 17.
- PostgreSQL scripts live under `Database/`.
- Backend is not Dockerized; Infrastructure may provide Docker Compose for PostgreSQL/Redis/MinIO.
- External pages are for customers; internal pages are for staff/admin.
